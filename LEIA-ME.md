# Site CIT Agency

- `index.html`: página-mãe (link da bio)
- `data/eventos.json`: calendário da página-mãe
- `data/links.json`: botões de acesso rápido
- `eventos/<nome>/`: uma pasta por evento (`index.html` + `evento.json` + `img/`)
- `template/`: modelo para criar um evento novo
- `css/`, `js/`, `assets/`: arquivos compartilhados

Para atualizar o site, edite os arquivos `.json`. O código não precisa ser tocado.
